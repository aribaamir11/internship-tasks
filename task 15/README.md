# Furnitur - Task 10

A responsive furniture e-commerce homepage built with HTML, CSS, and vanilla JavaScript.

## Features

- Products rendered dynamically from a JavaScript array
- Instant category filtering
- Product name search
- Persistent shopping cart using `localStorage`
- Cart drawer with quantity controls and totals
- Responsive desktop, tablet, and mobile layouts

## Run

Open `index.html` in a browser, or serve the folder with a local development server.
